# TOPCIT 시험 안내

## 시험 개요

| 항목 | 내용 |
|------|------|
| 주관 | 과학기술정보통신부, 정보통신기획평가원(IITP) |
| 목적 | SW 개발·IT 직무 역량을 객관적으로 측정 |
| 대상 | 대학생, 취업 준비생, 재직자 |
| 시험 횟수 | 연 2회 (상반기/하반기) |
| 공식 사이트 | [www.topcit.or.kr](https://www.topcit.or.kr) |

---

## 시험 구성

### 문항 수 및 시간

| 구분 | 내용 |
|------|------|
| 총 문항 | 약 80문항 |
| 시험 시간 | 150분 |
| 문제 유형 | 객관식(4지선다) + 단답형 + 서술형 |

### 영역별 구성

| 영역 (공식 명칭) | 주요 내용 | 구분 |
|------|-----------|------|
| 1. 소프트웨어 개발 | SW공학, 알고리즘, 자료구조, OOP, 테스팅, 형상관리 | 기술영역 |
| 2. 데이터 이해와 활용 | 데이터 모델링, DB설계, SQL, 정규화, NoSQL | 기술영역 |
| 3. 시스템 아키텍처 이해와 활용 | OSI/TCP-IP, TCP/UDP, HTTP, 네트워크 장비, 클라우드 | 기술영역 |
| 4. 정보보안 이해와 활용 | 암호화, 인증, 접근통제, 공격 유형, ISMS, OWASP | 기술영역 |
| 5. IT 비즈니스와 윤리 | IT서비스, 클라우드, 신기술, IT윤리 | 비즈니스영역 |
| 6. 프로젝트 관리 및 테크니컬 커뮤니케이션 | 프로젝트관리, WBS, CPM, 원가/품질/위험관리, 문서작성 | 비즈니스영역 |

## 문제 유형별 특징

### 객관식 (4지선다)
- 개념 정의, 특성 구별, 알고리즘 동작 결과 등
- 예: "다음 중 안정 정렬이 아닌 것은?"

### 단답형
- 개념어, 용어, 약어를 직접 작성
- 예: "TCP 연결 설정 시 사용하는 3단계 과정을 무엇이라 하는가?"

### 서술형
- 개념 설명, 차이점 비교, 동작 원리 기술
- 예: "정규화의 필요성과 1NF~3NF 단계를 설명하시오."

## 학습 전략

### 단계별 학습 순서

```
1단계: 이론 정리
각 영역 문서를 읽으며 개념 이해

2단계: 핵심 요약 카드 암기
시험에 자주 나오는 핵심만 빠르게 복습

3단계: 영역별 연습문제 풀기
30문항씩 풀고 오답 노트 작성

4단계: 통합 모의고사
전 영역 30문항으로 실전 감각 익히기

5단계: 오답 복습
오답 노트 기반으로 취약 개념 집중 보완
```

### 영역별 출제 비중 (예상)

| 영역 | 예상 비중 |
|------|-----------|
| 소프트웨어 개발 | 약 25% |
| 데이터 이해와 활용 | 약 20% |
| 시스템 아키텍처 이해와 활용 | 약 20% |
| 정보보안 이해와 활용 | 약 15% |
| IT 비즈니스와 윤리 | 약 10% |
| 프로젝트 관리 및 테크니컬 커뮤니케이션 | 약 10% |

### 서술형 대비 포인트

서술형은 단순 암기보다 **개념을 자신의 말로 설명**할 수 있어야 합니다.

아래 주제는 서술형으로 자주 출제됩니다:

- 정규화 단계별 설명 및 이상 현상 (1NF~3NF)
- TCP vs UDP 비교
- ACID 속성 각각의 의미
- 공개키/대칭키 암호화 차이와 HTTPS 동작 방식
- OSI 7계층 각 계층의 역할
- 프로젝트 위험 관리 4가지 전략 (회피/전가/완화/수용)
- 빅데이터 3V 설명
- 응집도와 결합도 개념 및 좋은 설계 방향
- 접근통제 모델 3가지 (DAC/MAC/RBAC) 비교
- WBS, CPM 개념 및 차이
