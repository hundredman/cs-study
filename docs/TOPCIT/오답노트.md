## 핵심 암기 사항

자주 출제되는 암기 포인트를 직접 추가하세요.

### 숫자로 외워야 할 것들

| 항목 | 값 |
|------|-----|
| 8비트 2의 보수 범위 | -128 ~ 127 |
| IEEE 754 단정도 구성 | 부호(1) + 지수(8) + 가수(23) |
| DHCP 4단계 | Discover → Offer → Request → ACK |
| PERT 공식 | (낙관 + 4×최빈 + 비관) / 6 |
| 가용성 공식 | MTBF / (MTBF + MTTR) |
| 99.999% 다운타임 | 연간 약 5.26분 |
| TCP 3-way | SYN → SYN+ACK → ACK |
| TCP 4-way | FIN → ACK → FIN → ACK |

### 자주 혼동되는 쌍

| 항목 A | 항목 B | 구분 포인트 |
|--------|--------|-------------|
| 인증(Authentication) | 인가(Authorization) | 신원 확인 vs 권한 확인 |
| IDS | IPS | 탐지+알림 vs 탐지+차단 |
| MTTR | RTO | 실제 평균 복구 시간 vs 목표 복구 시간 |
| WHERE | HAVING | 그룹화 전 필터 vs 그룹화 후 필터 |
| 공유락 | 배타락 | 읽기/여럿 가능 vs 쓰기/독점 |
| 쿠키 | 세션 | 클라이언트 저장 vs 서버 저장 |
| DFS | BFS | 스택/재귀 vs 큐/최단경로 |
| 대칭키 | 비대칭키 | 빠름/키배송문제 vs 느림/키배송안전 |
