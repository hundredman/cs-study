# 프로젝트 관리

## 1. 프로젝트 관리 개요

**프로젝트**: 특정 목표 달성을 위한 **일시적인** 작업 (시작과 끝이 있음)

### PMI / PMBOK

PMI(프로젝트 관리 협회)가 정의한 프로젝트 관리 지식 체계입니다.

#### 5대 프로세스 그룹

| 단계 | 설명 |
|------|------|
| 착수(Initiating) | 프로젝트 승인, 목표 정의 |
| 기획(Planning) | 범위, 일정, 비용, 위험 계획 수립 |
| 실행(Executing) | 계획에 따라 작업 수행 |
| 감시 및 통제(Monitoring & Controlling) | 진척도 측정, 변경 관리 |
| 종료(Closing) | 인수인계, 교훈 문서화 |

#### 10대 지식 영역

통합, 범위, 일정, 원가, 품질, 자원, 의사소통, 위험, 조달, 이해관계자

## 2. 일정 관리

### WBS (Work Breakdown Structure)

프로젝트 작업을 **계층적으로 분해**한 구조도입니다.

```
프로젝트
├── 1. 요구사항 분석
│   ├── 1.1 현황 조사
│   └── 1.2 요구사항 문서화
├── 2. 설계
│   ├── 2.1 아키텍처 설계
│   └── 2.2 DB 설계
└── 3. 개발
    ├── 3.1 백엔드 개발
    └── 3.2 프론트엔드 개발
```

### 간트 차트 (Gantt Chart)

작업별 **시작/종료 일정을 막대 형태**로 시각화합니다.

- 작업 간 의존 관계 표현
- 진척도 모니터링 용이
- 단점: 자원 배분 및 작업 간 상세 의존 관계 표현 어려움

### CPM (Critical Path Method)

프로젝트에서 **가장 긴 경로(임계 경로)** 를 찾아 전체 기간을 결정합니다.

```
A(3일) → C(2일) → E(4일) = 9일  ← 임계 경로
A(3일) → D(5일)            = 8일
B(2일) → E(4일)            = 6일
```

- **임계 경로**: 여유 시간(Float)이 0인 경로
- 임계 경로 상의 작업이 지연되면 전체 프로젝트 지연

### PERT (Program Evaluation and Review Technique)

불확실한 작업 기간을 **낙관/비관/최빈값** 3가지로 산정합니다.

```
기대 시간 = (낙관치 + 4 × 최빈치 + 비관치) / 6
```

## 3. 위험 관리

### 위험 관리 프로세스

1. **식별**: 잠재적 위험 목록 작성
2. **분석**: 발생 가능성 × 영향도 → 위험 우선순위
3. **대응 계획**: 회피/완화/전가/수용
4. **모니터링**: 지속적 위험 감시

### 위험 대응 전략

| 전략 | 설명 |
|------|------|
| 회피(Avoid) | 위험 원인 제거 |
| 완화(Mitigate) | 발생 가능성 또는 영향 감소 |
| 전가(Transfer) | 보험, 외주 등으로 위험 이전 |
| 수용(Accept) | 위험 감수 (낮은 위험) |

## 4. 애자일 / 스크럼

### 애자일 (Agile)

반복적·점진적 개발로 **변화에 빠르게 대응**하는 방법론입니다.

#### 애자일 선언 4가지 가치

1. **프로세스보다** 개인과 상호작용
2. **문서보다** 동작하는 소프트웨어
3. **계약 협상보다** 고객과의 협력
4. **계획을 따르기보다** 변화에 대응

### 스크럼 (Scrum)

애자일 방법론 중 가장 많이 사용되는 프레임워크입니다.

#### 주요 역할

| 역할 | 설명 |
|------|------|
| 제품 오너(PO) | 제품 백로그 관리, 우선순위 결정 |
| 스크럼 마스터(SM) | 팀 지원, 장애물 제거, 프로세스 코치 |
| 개발팀 | 스프린트 내 개발 수행 |

#### 스크럼 이벤트

| 이벤트 | 설명 |
|--------|------|
| 스프린트 | 1~4주 반복 개발 주기 |
| 스프린트 계획 | 스프린트 목표와 작업 선정 |
| 데일리 스크럼 | 매일 15분 진척 공유 |
| 스프린트 리뷰 | 완성된 기능 시연 |
| 스프린트 회고 | 프로세스 개선 논의 |

#### 스크럼 산출물

| 산출물 | 설명 |
|--------|------|
| 제품 백로그 | 전체 요구사항 목록 |
| 스프린트 백로그 | 현재 스프린트 작업 목록 |
| 소프트웨어 증분 | 스프린트마다 완성된 기능 |

## 시험 포인트

- **PMBOK 5대 프로세스**: 착수→기획→실행→감시통제→종료
- **WBS**: 작업의 계층적 분해
- **CPM 임계 경로**: Float=0, 지연 시 전체 일정 지연
- **PERT 공식**: (낙관 + 4×최빈 + 비관) / 6
- **애자일 4가지 가치** 암기
- **스크럼 3역할**: PO, SM, 개발팀
- **스프린트**: 1~4주 반복 개발 주기
