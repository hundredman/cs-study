# IT 서비스 관리

## 1. ITIL (IT Infrastructure Library)

IT 서비스 관리의 **모범 사례(Best Practice)** 프레임워크입니다.

### ITIL 4 핵심 개념

| 개념 | 설명 |
|------|------|
| 서비스 가치 시스템(SVS) | IT 서비스가 가치를 창출하는 방법 정의 |
| 서비스 가치 체인 | 계획→개선→참여→설계/전환→획득/구축→제공/지원 |
| 거버넌스 | 방향성 평가 및 감시 |
| 지속적 개선 | 서비스와 프로세스를 계속 개선 |

### ITIL 서비스 관리 프로세스 (주요)

| 프로세스 | 설명 |
|----------|------|
| 인시던트 관리 | 서비스 장애 신속 복구 |
| 문제 관리 | 인시던트의 근본 원인 파악 및 재발 방지 |
| 변경 관리 | 변경 사항을 통제된 방식으로 적용 |
| 구성 관리 | IT 자산 및 구성 정보 관리 (CMDB) |
| 릴리즈 관리 | 새 버전의 배포 계획 및 실행 |
| 서비스 데스크 | 사용자 단일 접점(SPOC) |

> **인시던트 vs 문제**: 인시던트는 증상(빠른 복구), 문제는 근본 원인(재발 방지)

## 2. SLA (Service Level Agreement)

서비스 제공자와 고객 간의 **서비스 수준 협약**입니다.

### 주요 지표

| 지표 | 설명 |
|------|------|
| 가용성(Availability) | 서비스 정상 운영 시간 비율 (예: 99.9%) |
| MTTR (평균 복구 시간) | 장애 발생 후 복구까지 평균 시간 |
| MTBF (평균 장애 간격) | 장애 발생 간격의 평균 시간 |
| 응답 시간 | 요청에 대한 응답까지 걸리는 시간 |
| 처리량(Throughput) | 단위 시간당 처리 가능한 요청 수 |

### 가용성 계산

```
가용성 = MTBF / (MTBF + MTTR) × 100%

예) MTBF = 720시간, MTTR = 1시간
    가용성 = 720 / (720 + 1) × 100 ≈ 99.86%
```

#### 가용성 수준별 다운타임

| 가용성 | 연간 다운타임 |
|--------|---------------|
| 99% | 약 87.6시간 |
| 99.9% | 약 8.76시간 |
| 99.99% | 약 52.6분 |
| 99.999% (Five Nines) | 약 5.26분 |

## 3. IT 거버넌스

IT 자원을 **조직의 목표에 맞게 통제하고 관리**하는 체계입니다.

### COBIT (Control Objectives for IT)

IT 거버넌스 및 관리 프레임워크입니다.

- **목적**: IT가 비즈니스 목표 달성을 지원하도록 통제
- **구성**: 거버넌스(EDM) + 관리(APO, BAI, DSS, MEA)

### IT 거버넌스 5대 영역

| 영역 | 설명 |
|------|------|
| 전략적 정렬 | IT 전략과 비즈니스 전략 연계 |
| 가치 전달 | IT 투자 대비 가치 실현 |
| 위험 관리 | IT 관련 위험 식별 및 관리 |
| 자원 관리 | IT 자원(인력, 기술, 정보) 최적화 |
| 성과 측정 | IT 성과 모니터링 및 보고 |

## 4. 아웃소싱 (Outsourcing)

IT 업무의 일부 또는 전부를 **외부 전문 업체에 위탁**합니다.

| 유형 | 설명 |
|------|------|
| ITO (IT 아웃소싱) | IT 인프라, 운영 위탁 |
| BPO (비즈니스 프로세스 아웃소싱) | 특정 비즈니스 프로세스 위탁 |
| 클라우드 서비스 | IaaS/PaaS/SaaS 형태의 아웃소싱 |

---

## 시험 포인트

- **ITIL**: IT 서비스 관리 모범 사례 프레임워크
- **인시던트 vs 문제**: 증상(빠른 복구) vs 근본 원인(재발 방지)
- **SLA**: 서비스 수준 협약 — 가용성, MTTR, MTBF 포함
- **MTTR**: 복구 시간, **MTBF**: 장애 간격
- **가용성 공식**: MTBF / (MTBF + MTTR)
- **Five Nines(99.999%)**: 연간 약 5분 다운타임
- **COBIT**: IT 거버넌스 프레임워크
