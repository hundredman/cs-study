# 신기술 트렌드

## 1. 클라우드 컴퓨팅

인터넷을 통해 **컴퓨팅 자원을 서비스 형태**로 제공합니다.

### 서비스 모델

| 모델 | 전체 명칭 | 제공 범위 | 예시 |
|------|-----------|-----------|------|
| IaaS | Infrastructure as a Service | 가상 서버, 스토리지, 네트워크 | AWS EC2, Azure VM |
| PaaS | Platform as a Service | 개발 플랫폼, 런타임 환경 | Google App Engine, Heroku |
| SaaS | Software as a Service | 완성된 소프트웨어 | Gmail, Office 365, Salesforce |

```
사용자 관리 범위:
IaaS: OS + 미들웨어 + 앱 직접 관리
PaaS: 앱만 관리
SaaS: 아무것도 관리 안 함
```

### 배포 모델

| 모델 | 설명 |
|------|------|
| 퍼블릭 클라우드 | 공개 인터넷으로 제공, 다수 사용자 공유 |
| 프라이빗 클라우드 | 단일 조직 전용 |
| 하이브리드 클라우드 | 퍼블릭 + 프라이빗 혼합 |
| 멀티 클라우드 | 여러 클라우드 공급자 동시 사용 |

### 클라우드 특성

- **온디맨드 셀프서비스**: 필요할 때 즉시 자원 할당
- **광대역 네트워크 접근**: 어디서든 접근 가능
- **자원 풀링**: 다수 고객이 자원 공유
- **신속한 탄력성**: 수요에 따라 자동 확장/축소
- **측정 가능한 서비스**: 사용량 기반 과금

## 2. 빅데이터 (Big Data)

기존 방식으로 처리하기 어려운 **대용량·다양·고속** 데이터입니다.

### 3V (빅데이터 특성)

| 특성 | 설명 |
|------|------|
| Volume (규모) | 데이터 양이 매우 많음 (TB, PB 단위) |
| Velocity (속도) | 데이터 생성·수집·처리 속도가 빠름 |
| Variety (다양성) | 정형·반정형·비정형 데이터 혼재 |

> 확장: 5V = 3V + Veracity(정확성) + Value(가치)

### 빅데이터 처리 기술

| 기술 | 설명 |
|------|------|
| Hadoop | 분산 파일 시스템(HDFS) + MapReduce |
| Spark | 인메모리 분산 처리, Hadoop보다 빠름 |
| Kafka | 고처리량 분산 메시지 스트리밍 |
| Hive | Hadoop 위에서 SQL과 유사한 쿼리 |

### 데이터 처리 방식

| 방식 | 설명 | 예시 |
|------|------|------|
| 배치 처리 | 데이터를 모아 일괄 처리 | Hadoop MapReduce |
| 스트림 처리 | 실시간으로 데이터 처리 | Spark Streaming, Kafka |

## 3. AI / 머신러닝

### 주요 개념

| 개념 | 설명 |
|------|------|
| AI (인공지능) | 인간 지능을 모방하는 기술의 총칭 |
| 머신러닝(ML) | 데이터로부터 패턴을 학습하는 AI 기법 |
| 딥러닝(DL) | 인공 신경망 기반의 머신러닝 |

### 머신러닝 유형

| 유형 | 설명 | 예시 |
|------|------|------|
| 지도학습 | 정답 레이블이 있는 데이터로 학습 | 분류, 회귀 |
| 비지도학습 | 레이블 없이 패턴 발견 | 클러스터링, 차원 축소 |
| 강화학습 | 보상/벌점으로 최적 행동 학습 | 게임 AI, 자율주행 |

### 생성형 AI (Generative AI)

- **LLM(대형 언어 모델)**: GPT, Claude 등
- 텍스트, 이미지, 코드 생성
- 트랜스포머(Transformer) 아키텍처 기반

## 4. IoT (Internet of Things)

**물리적 사물이 인터넷에 연결**되어 데이터를 수집·교환합니다.

### 구성 요소

| 계층 | 설명 |
|------|------|
| 사물(Device) | 센서, 액추에이터 내장 디바이스 |
| 연결(Network) | WiFi, Bluetooth, LTE, LoRa |
| 플랫폼(Platform) | 데이터 수집·처리·저장 |
| 서비스(Application) | 스마트홈, 스마트팩토리, 헬스케어 |

### 주요 통신 프로토콜

| 프로토콜 | 특징 |
|----------|------|
| MQTT | 경량 발행/구독 방식, IoT 표준 |
| CoAP | HTTP와 유사, 저전력 디바이스용 |
| LoRa | 장거리·저전력 통신 |

## 5. 블록체인 (Blockchain)

데이터를 **블록으로 연결**하여 분산 저장하는 기술입니다.

### 핵심 특성

| 특성 | 설명 |
|------|------|
| 분산성 | 중앙 서버 없이 P2P 네트워크에 분산 저장 |
| 투명성 | 모든 참여자가 데이터 조회 가능 |
| 불변성 | 한 번 기록된 데이터 변조 극히 어려움 |
| 합의 메커니즘 | PoW(작업증명), PoS(지분증명) |

### 블록 구조

```
[블록 n]                    [블록 n+1]
이전 해시 → ──────────────> 이전 해시 (= 블록 n의 해시)
현재 해시                   현재 해시
트랜잭션 데이터              트랜잭션 데이터
```

### 활용 사례

- **암호화폐**: 비트코인, 이더리움
- **스마트 컨트랙트**: 조건 충족 시 자동 계약 실행
- **공급망 관리**: 제품 이력 추적
- **의료 기록**: 환자 데이터 안전한 공유

## 시험 포인트

- **IaaS/PaaS/SaaS**: 제공 범위 차이 (인프라/플랫폼/소프트웨어)
- **빅데이터 3V**: Volume, Velocity, Variety
- **Hadoop**: HDFS + MapReduce (배치 처리)
- **Spark**: 인메모리, Hadoop보다 빠름
- **ML 3종류**: 지도/비지도/강화학습
- **IoT MQTT**: 경량 발행/구독, IoT 표준 프로토콜
- **블록체인**: 분산, 불변, 투명 — PoW/PoS 합의
