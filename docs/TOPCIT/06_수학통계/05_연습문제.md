## 정답

| 번호 | 정답 | 해설 |
|------|------|------|
| Q1 | **3** | |A∪B| = |A|+|B|-|A∩B| = 4+4-2 = 6 |
| Q2 | **3** | 대우: ¬q→¬p (원래 명제와 동치) |

| Q4 | **1** | XOR: 서로 다를 때 True → T XOR F = True |
| Q5 | **1** | P(짝수)=1/2, P(3이하)=1/2 → 1/2 × 1/2 = 1/4 |
| Q6 | **2** | 베이즈: 사전 확률 + 새 증거 → 사후 확률로 갱신 |
| Q7 | **2** | B(n,p): E(X)=np=10×0.5=5, Var=np(1-p)=10×0.5×0.5=2.5 |
| Q8 | **2** | ±2σ ≈ 95% (±1σ≈68%, ±3σ≈99.7%) |
| Q9 | **1** | det = (2×4)-(3×1) = 8-3 = 5 |
| Q10 | **1** | A(m×n)×B(n×p)=C(m×p) → 2×4 |
| Q11 | **2** | det(A)=0 이면 특이 행렬 → 역행렬 없음 |
| Q12 | **2** | 25 = 16+8+1 = 2⁴+2³+2⁰ = 11001 |
