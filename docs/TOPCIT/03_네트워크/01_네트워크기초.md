# 네트워크 기초

## 1. OSI 7계층

네트워크 통신을 7단계로 표준화한 모델입니다.

| 계층 | 이름 | 주요 기능 | 프로토콜/장비 |
|------|------|-----------|---------------|
| 7 | 응용(Application) | 사용자 인터페이스, 서비스 제공 | HTTP, FTP, SMTP, DNS |
| 6 | 표현(Presentation) | 데이터 형식 변환, 암호화, 압축 | SSL/TLS, JPEG |
| 5 | 세션(Session) | 연결 설정/유지/종료 | NetBIOS |
| 4 | 전송(Transport) | 종단 간 신뢰성 있는 전송 | TCP, UDP |
| 3 | 네트워크(Network) | 논리 주소(IP), 라우팅 | IP, ICMP, 라우터 |
| 2 | 데이터링크(Data Link) | 물리 주소(MAC), 오류 검출 | Ethernet, 스위치 |
| 1 | 물리(Physical) | 비트 전송, 전기 신호 | 케이블, 허브 |

> 암기법: **아파서 탄 네데물** (응용-표현-세션-전송-네트워크-데이터링크-물리)

---

## 2. TCP/IP 4계층

실제 인터넷에서 사용하는 모델입니다.

| TCP/IP 계층 | OSI 계층 대응 | 프로토콜 |
|-------------|--------------|----------|
| 응용(Application) | 5, 6, 7계층 | HTTP, FTP, DNS, SMTP |
| 전송(Transport) | 4계층 | TCP, UDP |
| 인터넷(Internet) | 3계층 | IP, ICMP, ARP |
| 네트워크 액세스 | 1, 2계층 | Ethernet, Wi-Fi |

## 3. IP 주소

### IPv4

- **32비트** 주소 체계 (약 43억 개)
- 표기: `192.168.0.1` (8비트씩 4묶음, 점으로 구분)

#### 주소 클래스

| 클래스 | 범위 | 용도 |
|--------|------|------|
| A | 0.0.0.0 ~ 127.255.255.255 | 대형 네트워크 |
| B | 128.0.0.0 ~ 191.255.255.255 | 중형 네트워크 |
| C | 192.0.0.0 ~ 223.255.255.255 | 소형 네트워크 |
| D | 224.0.0.0 ~ 239.255.255.255 | 멀티캐스트 |

#### 사설 IP (Private IP)

| 클래스 | 범위 |
|--------|------|
| A | 10.0.0.0 ~ 10.255.255.255 |
| B | 172.16.0.0 ~ 172.31.255.255 |
| C | 192.168.0.0 ~ 192.168.255.255 |

### IPv6

- **128비트** 주소 체계 (거의 무한대)
- 표기: `2001:0db8:85a3::8a2e:0370:7334` (16진수, 콜론 구분)

## 4. 서브넷 마스크 / CIDR

### 서브넷 마스크

네트워크 부분과 호스트 부분을 구분합니다.

```
IP:      192.168.1.100
Mask:    255.255.255.0
Network: 192.168.1.0
Host:    100
```

### CIDR (Classless Inter-Domain Routing)

`/비트수` 형식으로 서브넷 마스크를 표현합니다.

```
192.168.1.0/24  → 255.255.255.0  → 호스트 254개
192.168.1.0/16  → 255.255.0.0    → 호스트 65534개
```

---

## 5. DNS (Domain Name System)

도메인 이름을 IP 주소로 변환합니다.

```
www.google.com → 142.250.196.100
```

#### DNS 조회 과정

1. 브라우저 캐시 확인
2. OS 캐시 확인 (`/etc/hosts`)
3. Local DNS 서버 조회
4. Root DNS → TLD DNS → Authoritative DNS 순서로 재귀 조회

---

## 6. DHCP (Dynamic Host Configuration Protocol)

IP 주소를 **자동으로 할당**합니다.

- 클라이언트가 네트워크에 접속하면 DHCP 서버에서 IP, 서브넷 마스크, 게이트웨이, DNS 주소 자동 부여
- 임대 시간(Lease Time) 만료 후 갱신 또는 반납

---

## 7. ARP (Address Resolution Protocol)

IP 주소로 **MAC 주소를 알아냅니다**.

```
"192.168.1.5의 MAC 주소가 뭐야?" → 브로드캐스트
해당 IP 소유자가 자신의 MAC 주소로 응답
```

> ARP 테이블(캐시)에 IP-MAC 매핑 정보 저장

---

## 시험 포인트

- **OSI 7계층** 순서와 각 계층의 역할/프로토콜
- **TCP/IP 4계층**과 OSI 계층의 대응 관계
- **DNS**: 도메인 → IP 변환
- **DHCP**: IP 자동 할당
- **ARP**: IP → MAC 주소 변환
- **사설 IP 대역** 3가지 (10.x.x.x / 172.16~31.x.x / 192.168.x.x)
- **CIDR /24** = 255.255.255.0 = 호스트 254개
