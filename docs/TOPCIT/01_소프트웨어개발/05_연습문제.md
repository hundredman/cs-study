## 정답

| 번호 | 정답 | 해설 |
|------|------|------|
| Q1 | **4** | 퀵 정렬은 불안정 정렬 (버블·삽입·병합은 안정 정렬) |
| Q2 | **2** | 중간값 5 → 9>5 오른쪽 → 중간값 9 → 일치 (2회) |
| Q3 | **3** | 병합 정렬은 항상 O(n log n) / 퀵 정렬 최악은 O(n²) |
| Q4 | **2** | 다익스트라는 음수 가중치 처리 불가 (벨만-포드가 가능) |
| Q5 | **2** | 스택은 LIFO (큐는 FIFO) |
| Q6 | **2** | 높이 h의 완전 이진 트리 최대 노드 = 2^(h+1)-1. h=3이면 15개 → 높이 3, 레벨 수 4 |
| Q7 | **4** | 체이닝은 분리 연결법으로 개방 주소법과 다른 방식 |
| Q8 | **4** | "계약 협상보다 **고객과의 협력**" 이 맞는 표현 |
| Q9 | **3** | 제품 백로그 관리는 PO의 역할 |
| Q10 | **3** | 기본 경로 테스트는 화이트박스 테스트 기법 |
| Q11 | **2** | OCP(Open-Closed Principle): 확장에 열림, 변경에 닫힘 |
| Q12 | **3** | 싱글톤·팩토리·빌더·프로토타입·추상팩토리 → 생성 패턴 |
| Q13 | **3** | Java 7 이하 인터페이스는 추상 메서드만 가능 (Java 8부터 default 메서드 허용) |
