## 2영역 — 데이터베이스

### 정규화 단계

| 단계 | 제거 대상 | 핵심 |
|------|-----------|------|
| 1NF | — | 원자값 |
| 2NF | 부분 함수 종속 | 기본키 일부에만 종속 제거 |
| 3NF | 이행 함수 종속 | A→B→C 관계 제거 |
| BCNF | 결정자가 후보키 아닌 경우 | 모든 결정자=후보키 |

### 이상 현상: 삽입 / 삭제 / 갱신 이상

### SQL 실행 순서
```
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
```

### 조인 비교

| 종류 | 결과 |
|------|------|
| INNER JOIN | 양쪽 일치 행만 |
| LEFT JOIN | 왼쪽 전체 + 오른쪽 일치 (없으면 NULL) |
| RIGHT JOIN | 오른쪽 전체 + 왼쪽 일치 |
| FULL OUTER | 양쪽 모두 |

### 트랜잭션 ACID

| 속성 | 의미 |
|------|------|
| Atomicity | All or Nothing |
| Consistency | 일관된 상태 유지 |
| Isolation | 트랜잭션 간 독립 |
| Durability | COMMIT 후 영구 반영 |

### 격리 수준 (낮음 → 높음)

```
READ UNCOMMITTED → READ COMMITTED → REPEATABLE READ → SERIALIZABLE
더티리드 방지X → 방지O → + 반복불가능 방지 → + 팬텀리드 방지
```

### NoSQL 4종류

| 종류 | 예시 | 용도 |
|------|------|------|
| 키-값 | Redis | 캐싱, 세션 |
| 문서 | MongoDB | 콘텐츠, 카탈로그 |
| 컬럼 패밀리 | Cassandra | 시계열, 대규모 쓰기 |
| 그래프 | Neo4j | SNS, 추천 |

### CAP 정리: 3가지 중 2가지만 선택 가능 (P는 필수)

## 3영역 — 네트워크

### OSI 7계층 (아파서 탄 네데물)

| 계층 | 이름 | PDU | 프로토콜/장비 |
|------|------|-----|--------------|
| 7 | 응용 | — | HTTP, DNS, FTP |
| 6 | 표현 | — | SSL/TLS, JPEG |
| 5 | 세션 | — | NetBIOS |
| 4 | 전송 | 세그먼트 | TCP, UDP |
| 3 | 네트워크 | 패킷 | IP, 라우터 |
| 2 | 데이터링크 | 프레임 | MAC, 스위치 |
| 1 | 물리 | 비트 | 케이블, 허브 |

### TCP vs UDP

| 항목 | TCP | UDP |
|------|-----|-----|
| 연결 | 연결 지향 | 비연결 |
| 신뢰성 | 보장 | 미보장 |
| 속도 | 느림 | 빠름 |
| 용도 | HTTP, FTP | DNS, 게임, 스트리밍 |

### TCP 핸드셰이크
- 연결: **SYN → SYN+ACK → ACK** (3-way)
- 종료: **FIN → ACK → FIN → ACK** (4-way)

### 주요 포트
```
20/21=FTP  22=SSH  23=Telnet  25=SMTP
53=DNS  80=HTTP  110=POP3  443=HTTPS
```

### HTTP 메서드 멱등성
- 있음: GET, PUT, DELETE, HEAD
- 없음: **POST, PATCH**

### 장비 계층
```
허브(1계층) → 스위치(2계층, MAC) → 라우터(3계층, IP)
IDS=탐지+알림 / IPS=탐지+자동차단
L4=IP+포트 기반 / L7=URL+헤더 기반
```

## 4영역 — 정보보안

### 암호화 비교

| 구분 | 대칭키 | 비대칭키 |
|------|--------|----------|
| 키 | 1개 (동일) | 2개 (공개+개인) |
| 속도 | 빠름 | 느림 |
| 키 배송 | 문제 있음 | 안전 |
| 예시 | **AES** | **RSA** |

> **HTTPS**: 비대칭키로 대칭키 교환 → 대칭키로 통신

### 해시
- 단방향 (복호화 불가)
- SHA-256이 현재 표준
- 눈사태 효과: 입력 1비트 변경 → 출력 완전히 달라짐

### 디지털 서명
- 서명: **개인키**로 암호화
- 검증: **공개키**로 복호화

### 주요 공격과 방어

| 공격 | 방어 |
|------|------|
| SQL Injection | Prepared Statement |
| XSS | HTML 이스케이프, CSP, HTTPOnly |
| CSRF | CSRF 토큰, SameSite 쿠키 |
| DDoS/SYN Flood | CDN, SYN Cookie |

### CIA 트라이어드
- **기밀성**: 인가된 사용자만 접근
- **무결성**: 데이터 변조 없음
- **가용성**: 필요할 때 접근 가능

### 접근 제어 모델
```
DAC=소유자 결정 / MAC=시스템 강제(군사) / RBAC=역할 기반(기업)
```

## 6영역 — 수학/통계

### 집합 포함-배제
```
|A∪B| = |A| + |B| - |A∩B|
```

### 명제 논리 핵심

| 항목 | 내용 |
|------|------|
| 대우 | p→q 와 ¬q→¬p 는 동치 |
| XOR | 두 값이 **다를 때** 참 |
| 조건문 | p→q: p 참이고 q 거짓일 때만 거짓 |
| 드모르간 | ¬(A∧B)=¬A∨¬B, ¬(A∨B)=¬A∧¬B |

### 확률/통계 핵심

| 항목 | 공식 |
|------|------|
| 덧셈 법칙 | P(A∪B) = P(A)+P(B)-P(A∩B) |
| 조건부 확률 | P(A\|B) = P(A∩B)/P(B) |
| 이항 분포 | E(X)=np, Var=np(1-p) |
| 정규 분포 | ±1σ=68%, ±2σ=95%, ±3σ=99.7% |
| 분산 공식 | Var(aX+b) = a²Var(X) |

### 행렬 핵심
```
2×2 행렬식: ad - bc
역행렬 존재 조건: det(A) ≠ 0
행렬 곱: A(m×n) × B(n×p) = C(m×p)
```

### 진법 변환 핵심
```
10→2진수: 2로 나눈 나머지 역순
2진수 4비트 = 16진수 1자리
8비트 2의 보수: -128 ~ 127
IEEE 754 단정도: 부호(1)+지수(8)+가수(23)
```

## 자주 혼동되는 개념 쌍

| A | B | 구분 포인트 |
|---|---|-------------|
| 안정 정렬 (버·삽·병) | 불안정 (선·퀵·힙) | 같은 값의 순서 유지 여부 |
| WHERE | HAVING | 그룹화 전 vs 후 필터 |
| INNER JOIN | LEFT JOIN | 불일치 행 제외 vs 포함 |
| DDL (자동COMMIT) | DML (ROLLBACK 가능) | 구조 변경 vs 데이터 조작 |
| 더티리드 | 팬텀리드 | 커밋 안 된 데이터 vs 없던 행 나타남 |
| IDS | IPS | 탐지+알림 vs 탐지+자동차단 |
| AES | RSA | 대칭키 vs 비대칭키 |
| 인증 | 인가 | 신원 확인 vs 권한 확인 |
| MTTR | RTO | 실제 평균 복구 시간 vs 목표 복구 시간 |
| CPM | PERT | 임계 경로 vs 기대 시간 산정 |
| IaaS | PaaS | OS까지 관리 vs 앱만 관리 |
| 순열 (nPr) | 조합 (nCr) | 순서 있음 vs 순서 없음 |
