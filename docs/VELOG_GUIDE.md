# Velog 연동 가이드

## 1. Velog 설정

1. [velog.io](https://velog.io) 접속 후 GitHub 계정으로 로그인
2. 프로필 설정에서 블로그 이름 설정 (예: `@username`)
3. 시리즈 생성: **TOPCIT 준비** 시리즈 만들기

## 2. 태그 규칙

포스팅 시 아래 태그를 일관되게 사용하세요:

| 영역 | 태그 |
|------|------|
| 전체 | `TOPCIT`, `CS` |
| 소프트웨어 개발 | `알고리즘`, `자료구조`, `소프트웨어공학` |
| 데이터베이스 | `데이터베이스`, `SQL` |
| 네트워크 | `네트워크`, `TCP/IP` |
| 정보보안 | `정보보안`, `보안` |
| IT 비즈니스 | `IT비즈니스`, `프로젝트관리` |
| 수학/통계 | `이산수학`, `확률통계` |

## 3. 포스팅 워크플로우

```
로컬에서 Markdown 작성
        ↓
GitHub에 push (기록/버전 관리)
        ↓
Velog 에디터에 내용 복붙
        ↓
태그, 시리즈, 썸네일 설정 후 발행
```

## 4. GitHub ↔ Velog 파일 네이밍 규칙

- GitHub 파일명: `01_버블정렬.md`
- Velog 제목: `[TOPCIT] 소프트웨어개발 - 버블 정렬 완벽 정리`
