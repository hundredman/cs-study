    네트워크 연습문제¶

    네트워크 기초¶

    Q1. OSI 7계층 중 IP 주소를 기반으로 라우팅을 담당하는 계층은?

    1. 데이터링크 계층
    2. 네트워크 계층
    3. 전송 계층
    4. 세션 계층

    Q2. ARP 프로토콜의 역할로 옳은 것은?

    1. 도메인 이름을 IP 주소로 변환
    2. IP 주소를 MAC 주소로 변환
    3. MAC 주소를 IP 주소로 변환
    4. IP 주소를 포트 번호로 변환

    Q3. CIDR 표기 192.168.1.0/25에서 사용 가능한 호스트 수는?

    1. 62개
    2. 126개
    3. 254개
    4. 30개

    Q4. DHCP 프로토콜의 동작 순서로 옳은 것은?

    1. DISCOVER → REQUEST → OFFER → ACK
    2. DISCOVER → OFFER → REQUEST → ACK
    3. REQUEST → DISCOVER → OFFER → ACK
    4. OFFER → DISCOVER → REQUEST → ACK

    전송 계층¶

    Q5. TCP와 UDP의 비교로 옳지 않은 것은?

    1. TCP는 연결 지향, UDP는 비연결 지향이다
    2. UDP는 TCP보다 신뢰성이 높다
    3. TCP는 흐름 제어를 지원한다
    4. DNS는 UDP를 사용한다

    Q6. TCP 3-way Handshake의 순서로 옳은 것은?

    1. SYN → ACK → SYN+ACK
    2. SYN → SYN+ACK → ACK
    3. SYN+ACK → SYN → ACK
    4. ACK → SYN → SYN+ACK

    Q7. TCP 연결 종료 시 클라이언트가 마지막 ACK 전송 후 일정 시간 대기하는 이유는?

    1. 서버의 재연결 요청을 기다리기 위해
    2. 지연 도착 패킷을 처리하고 서버가 정상 종료되도록 보장하기 위해
    3. 새로운 연결을 위한 포트를 확보하기 위해
    4. 보안을 위해 연결을 완전히 초기화하기 위해

    Q8. 다음 설명에 해당하는 포트 번호는?

    보안 원격 접속에 사용되며, Telnet을 대체하는 프로토콜

    1. 21
    2. 22
    3. 23
    4. 25

    응용 계층¶

    Q9. HTTP 메서드 중 멱등성(Idempotency)이 없는 것은?

    1. GET
    2. PUT
    3. POST
    4. DELETE

    Q10. HTTP 상태 코드 401과 403의 차이로 옳은 것은?

    1. 401은 서버 오류, 403은 클라이언트 오류이다
    2. 401은 인증 필요(Unauthorized), 403은 권한 없음(Forbidden)이다
    3. 401은 리소스 없음, 403은 요청 오류이다
    4. 401과 403은 동일한 의미이다

    Q11. JWT(JSON Web Token)의 구조로 옳은 것은?

    1. Header.Body.Footer
    2. Header.Payload.Signature
    3. Token.Secret.Expire
    4. ID.Data.Hash

    Q12. REST API 설계 원칙 중 "서버가 클라이언트의 상태를 저장하지 않는다"는 것은?

    1. 캐시 가능
    2. 계층 구조
    3. 무상태(Stateless)
    4. 균일한 인터페이스

    네트워크 장비¶

    Q13. 다음 설명에 해당하는 장비는?

    MAC 주소 테이블을 유지하여 해당 포트로만 프레임을 전달하며, OSI 2계층에서 동작한다

    1. 허브
    2. 스위치
    3. 라우터
    4. 게이트웨이

    Q14. L4 로드밸런서와 L7 로드밸런서의 차이로 옳은 것은?

    1. L4는 URL 기반 분산, L7은 IP 기반 분산이다
    2. L4는 IP/포트 기반 분산, L7은 URL/헤더 기반 분산이다
    3. L4는 애플리케이션 계층, L7은 전송 계층에서 동작한다
    4. L4가 L7보다 더 세밀한 분산이 가능하다

    Q15. IDS와 IPS의 차이로 옳은 것은?

    1. IDS는 자동 차단, IPS는 알림만 발생한다
    2. IDS는 탐지 후 알림, IPS는 탐지 후 자동 차단한다
    3. IDS는 웹 애플리케이션 전용, IPS는 네트워크 전체에 적용된다
    4. IDS와 IPS는 동일한 기능을 한다

    Q16. IPv4에서 사설 IP 주소 대역이 아닌 것은?

    1. 10.0.0.0/8
    2. 172.16.0.0/12
    3. 192.168.0.0/16
    4. 203.0.113.0/24

    Q17. DNS 재귀 질의 순서로 옳은 것은?

    1. 클라이언트 → TLD DNS → 루트 DNS → 권한 DNS
    2. 클라이언트 → 로컬 DNS → 루트 DNS → TLD DNS → 권한 DNS
    3. 클라이언트 → 권한 DNS → 루트 DNS → 로컬 DNS
    4. 클라이언트 → 루트 DNS → 로컬 DNS → 권한 DNS

    Q18. TCP 혼잡 제어에서 Slow Start 단계의 동작으로 옳은 것은?

    1. 윈도우 크기를 매 RTT마다 1씩 선형 증가
    2. 윈도우 크기를 1에서 시작하여 매 RTT마다 2배 증가
    3. 타임아웃 발생 시 윈도우 크기를 절반으로 감소
    4. 3중 ACK 수신 시 윈도우 크기를 1로 초기화

    Q19. 다음 중 비연결 지향 프로토콜인 UDP를 사용하는 서비스는?

    1. 웹 브라우징(HTTP)
    2. 이메일 전송(SMTP)
    3. 파일 전송(FTP)
    4. 온라인 게임, 스트리밍

    Q20. NAT(Network Address Translation)의 주요 목적은?

    1. 도메인 이름을 IP 주소로 변환
    2. 사설 IP 주소를 공인 IP 주소로 변환하여 인터넷 통신
    3. MAC 주소를 IP 주소로 변환
    4. 패킷의 TTL을 증가시켜 수명 연장

    Q21. HTTP/2와 HTTP/3의 차이로 옳은 것은?

    1. HTTP/2는 UDP 기반, HTTP/3는 TCP 기반이다
    2. HTTP/3는 QUIC 프로토콜(UDP 기반)을 사용한다
    3. HTTP/2에서는 헤더 압축이 불가능하다
    4. HTTP/3는 HTTP/2보다 보안성이 낮다

    Q22. 다음 설명에 해당하는 프로토콜은?

    네트워크 상태 및 오류 메시지를 전달하며, ping 명령에서 사용된다.

    1. ARP
    2. DHCP
    3. ICMP
    4. SNMP

    복합 문제¶

    Q23. HTTPS 통신 과정에서 사용되는 프로토콜 스택을 올바르게 나열한 것은?

    1. HTTP → SSL/TLS → UDP → IP
    2. HTTP → SSL/TLS → TCP → IP
    3. HTTP → TCP → SSL/TLS → IP
    4. SSL/TLS → HTTP → TCP → IP

    Q24. 사용자가 https://www.example.com에 접속할 때 일어나는 과정의 순서로 옳은 것은?

    1. TCP 연결 → DNS 조회 → TLS Handshake → HTTP 요청
    2. DNS 조회 → TCP 연결 → TLS Handshake → HTTP 요청
    3. TLS Handshake → DNS 조회 → TCP 연결 → HTTP 요청
    4. DNS 조회 → TLS Handshake → TCP 연결 → HTTP 요청

    Q25. 웹 서버 앞에 L7 로드밸런서를 배치했을 때 가능한 기능으로 옳지 않은 것은?

    1. /api 경로는 API 서버로, /static은 정적 서버로 분기
    2. 특정 쿠키 값에 따라 특정 서버로 고정 연결
    3. OSI 3계층 IP 주소만으로 트래픽 분산
    4. HTTP 헤더 기반으로 모바일/PC 트래픽 분리

    Q26. 회사 내부 개발 서버(192.168.1.100:8080)에 외부 인터넷에서 접근하려 할 때 필요한 기술은?

    1. DNS 레코드 추가만으로 가능하다
    2. NAT 포트 포워딩 설정이 필요하다
    3. DHCP 서버 설정 변경이 필요하다
    4. ARP 테이블 수동 입력이 필요하다

    Q27. TCP 4-way Handshake에서 클라이언트가 마지막 ACK 후 TIME_WAIT 상태를 유지하는 이유와 관련이 없는 것은?

    1. 지연 도착한 패킷을 처리하기 위해
    2. 서버가 마지막 FIN을 재전송할 경우 재응답하기 위해
    3. 새 연결과 이전 연결의 패킷이 혼재되지 않도록 하기 위해
    4. 서버의 CPU 부하를 줄이기 위해

    Q28. 다음 중 세션 하이재킹(Session Hijacking) 방어에 직접 도움이 되는 것은?

    1. DDoS 방어 서비스 구축
    2. HTTPS 사용 + HTTPOnly·Secure 쿠키 설정
    3. DNS TTL 값 최소화
    4. 로드밸런서 IP 해시 알고리즘 사용

    Q29. 마이크로서비스 아키텍처에서 서비스 간 내부 통신에 UDP보다 TCP를 선호하는 이유로 옳은 것은?

    1. UDP가 TCP보다 보안이 취약하기 때문
    2. 서비스 간 데이터 정합성과 순서 보장이 필요하기 때문
    3. TCP가 UDP보다 전송 속도가 빠르기 때문
    4. UDP는 포트 번호를 지원하지 않기 때문

    Q30. 다음 네트워크 구성에서 DMZ의 역할로 옳은 것은?

    인터넷 → 방화벽1 → [DMZ: 웹서버] → 방화벽2 → 내부망(DB)
    1. 내부망과 인터넷 사이의 속도를 향상시킨다
    2. 외부에서 접근 가능한 서버를 내부망과 분리하여 내부망을 보호한다
    3. 내부망의 IP 주소를 공인 IP로 변환한다
    4. 트래픽을 여러 서버에 균등하게 분산한다

    정답¶

    번호 정답 해설
    Q1 2 네트워크 계층(3계층) = IP, 라우터
    Q2 2 ARP: IP → MAC 변환 / RARP: MAC → IP
    Q3 2 /25 = 호스트 비트 7개 → 2⁷-2 = 126개
    Q4 2 DHCP 순서: Discover → Offer → Request → ACK
    Q5 2 UDP는 TCP보다 신뢰성이 낮음 (빠르지만 비신뢰성)
    Q6 2 3-way: SYN → SYN+ACK → ACK
    Q7 2 TIME_WAIT: 지연 패킷 처리 + 서버의 마지막 FIN이 재전송될 경우 대비
    Q8 2 SSH = 22번 포트 (Telnet=23, FTP=21, SMTP=25)
    Q9 3 POST는 매번 새 리소스 생성 → 멱등성 없음
    Q10 2 401=Unauthorized(인증 필요), 403=Forbidden(인증됐지만 권한 없음)
    Q11 2 JWT = Header.Payload.Signature
    Q12 3 무상태(Stateless) = 서버가 클라이언트 상태 저장 안 함
    Q13 2 스위치: MAC 주소 기반, 2계층 / 허브: 브로드캐스트, 1계층
    Q14 2 L4: IP+포트 기반 / L7: URL·쿠키·헤더 기반 (더 세밀)
    Q15 2 IDS=탐지+알림, IPS=탐지+자동차단
    Q16 4 203.0.113.0/24는 문서용 공인 IP / 사설: 10.x, 172.16~31.x, 192.168.x
    Q17 2 DNS 재귀 질의: 클라이언트→로컬DNS→루트DNS→TLD→권한DNS
    Q18 2 Slow Start: 1부터 시작, 매 RTT마다 2배 증가
    Q19 4 게임·스트리밍: 속도 중요 → UDP (HTTP·SMTP·FTP는 TCP)
    Q20 2 NAT: 사설 IP→공인 IP 변환, IPv4 주소 고갈 완화
    Q21 2 HTTP/3 = QUIC(UDP 기반) / HTTP/2는 TCP 기반
    Q22 3 ICMP: 네트워크 오류/상태 메시지, ping에서 사용
    Q23 2 HTTPS = HTTP → SSL/TLS → TCP → IP 순으로 캡슐화
    Q24 2 순서: DNS 조회(IP 확인) → TCP 연결(3-way) → TLS Handshake → HTTP 요청
    Q25 3 L7은 URL·헤더·쿠키 기반 / IP만으로 분산하는 것은 L4의 기능
    Q26 2 사설 IP는 인터넷 직접 접근 불가 → NAT 포트 포워딩으로 외부 접근 허용
    Q27 4 TIME_WAIT는 서버 CPU 부하와 무관 / 패킷 지연·재전송 대비 목적
    Q28 2 세션 하이재킹: 쿠키 탈취 방지 → HTTPS + HTTPOnly(JS접근차단) + Secure(HTTPS만 전송)
    Q29 2 마이크로서비스: 데이터 정합성·순서 중요 → TCP의 신뢰성 필요
    Q30 2 DMZ: 외부 서비스 서버를 내부망 앞단에 격리 → 침입 시 내부망 보호
