    IT 비즈니스 연습문제¶

    프로젝트 관리¶

    Q1. PMBOK의 5대 프로세스 그룹을 올바른 순서로 나열한 것은?

    1. 착수 → 기획 → 감시통제 → 실행 → 종료
    2. 착수 → 기획 → 실행 → 감시통제 → 종료
    3. 기획 → 착수 → 실행 → 종료 → 감시통제
    4. 착수 → 실행 → 기획 → 감시통제 → 종료

    Q2. CPM(Critical Path Method)에서 임계 경로(Critical Path)의 정의로 옳은 것은?

    1. 가장 짧은 작업 경로
    2. 여유 시간(Float)이 0인 가장 긴 경로
    3. 가장 많은 자원이 투입되는 경로
    4. 위험도가 가장 높은 경로

    Q3. PERT 기법에서 기대 시간 산정 공식은?

    1. (낙관치 + 최빈치 + 비관치) / 3
    2. (낙관치 + 4 × 최빈치 + 비관치) / 6
    3. (낙관치 + 2 × 최빈치 + 비관치) / 4
    4. (낙관치 + 비관치) / 2

    Q4. 스크럼에서 스프린트 회고(Retrospective)의 목적으로 옳은 것은?

    1. 완성된 기능을 고객에게 시연한다
    2. 다음 스프린트의 백로그를 선정한다
    3. 팀의 작업 방식과 프로세스를 개선한다
    4. 제품 백로그의 우선순위를 조정한다

    Q5. 위험 대응 전략 중 보험 가입이나 외주를 통해 위험을 제3자에게 넘기는 전략은?

    1. 회피(Avoid)
    2. 완화(Mitigate)
    3. 전가(Transfer)
    4. 수용(Accept)
